## Token Discipline Directives (Claude 5.2 Fable)
- **Targeted File Reads**: NEVER read entire large files (>100 lines) into context (e.g., `index.html` [150KB], `assets/js/app.js` [674 lines]). ALWAYS use targeted line ranges (`StartLine`/`EndLine`) or search patterns.
- **Subagent Restraint**: Execute routine audits, searches, and file edits directly in the primary context. Never invoke subagents for single-turn or standard maintenance tasks.
- **Output Conciseness**: Summarize tool outputs concisely. Emit targeted diffs rather than full-file echoes.
- **Modular Doc Loading**: Do NOT load all documentation into global context. Read on-demand docs from `docs/agent/` only when a task specifically touches that subsystem.
- **Boundaries**: Strictly respect `.claudeignore`. Never inspect, search, or read files in `dist/`, `assets/css/tailwind.css`, `single-file/`, or `package-lock.json`.

## Non-Negotiable Guardrails
- **Immutable / Generated Files (Never Edit Directly)**:
  - `dist/`: Wiped and regenerated by `npm run build`.
  - `assets/css/tailwind.css`: Generated by `npm run css`. Edit `src/input.css` or `tailwind.config.js`.
  - `api/leads.csv`: Production customer data. Never commit, edit manually, or expose publicly.
  - `api/.htaccess`: Critical security barrier blocking web access to CSV/logs. Never remove.
  - `single-file/`: Deprecated archive; do not modify.
  - `package-lock.json`: Modify only via npm CLI.
- **Configuration Boundary**:
  - Edit contact info, phone, WhatsApp, GTM container ID, and customer reviews in `config.js` ONLY.
  - Never hardcode phone numbers or configuration strings in templates, pages, or JavaScript files.
- **Build Guardrails**:
  - Always run `SITE_URL=https://<domain>.ir npm run build` before release to ensure valid canonicals.
  - Re-run `npm run build` whenever modifying `scripts/build-pages.mjs`, `config.js`, `index.html`, or CSS classes.
